プライバシーポリシー

この文書は、YouTube チャンネル「なんでこの形 生き物と物理のなぜ」の運営者が使う投稿用のプログラム（以下「このアプリ」）の情報の扱いを定めます。

1. このアプリが行うこと

このアプリは、運営者自身の YouTube チャンネルに、運営者が作った動画を上げ、公開の予約と再生リストへの追加を行うためだけに使います。運営者以外の人は使いません。

2. 使う情報

このアプリは、Google の許可のしくみ（OAuth）を通じて、運営者のチャンネルへの投稿と、運営者のチャンネルの動画・再生リストの情報の読み取りだけを行います。ほかの人の個人情報は集めません。

3. 保存と共有

許可の情報は運営者のパソコンの中だけに保存し、第三者に渡したり売ったりしません。広告や分析のために使いません。

4. Google の情報の扱い

Google API から受け取った情報の利用と他のアプリへの受け渡しは、Google API Services User Data Policy（制限付き利用の要件を含む）に従います。

5. 許可の取り消し

許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
